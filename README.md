# 🎬 Parivartan — Video Transcoder

**A modern, dark-themed desktop video transcoder for H.265 ↔ H.264 conversion.**

Built with **Python**, **PyQt6**, and **FFmpeg** — featuring GPU acceleration, drag & drop, and real-time progress tracking.

## ✨ Features

### 🚀 Core Capabilities
- 🔄 **H.265 ↔ H.264 Conversion** — Seamless codec switching  
- ⚡ **GPU Acceleration (NVENC)** — Ultra-fast encoding with NVIDIA GPUs  
- 🖥️ **CPU Fallback** — Works on all systems automatically  

### 🎨 User Experience
- 📂 **Drag & Drop Support**  
- 🎨 **Modern Dark UI**  
- 🖼️ **Video Thumbnails**  
- 📊 **Real-Time Progress (Speed, ETA, %)**  

### 🔍 Advanced Tools
- 🔎 **Media Inspector** — Deep metadata view  
- 🎚️ **Quality Presets**
  - Original (Max Quality)  
  - Balanced (Recommended)  
  - Compressed (Smaller Size)  

### 📦 Flexibility
- 🎞️ **Multi-format Output** — MP4, MOV, MKV  
- 📝 **Logging System** — Debug logs saved automatically
